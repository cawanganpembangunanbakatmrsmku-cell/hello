I will provide you with the complete, production-ready `index.html` file that is ready to be uploaded to GitHub for GitHub Pages hosting.

Untuk membawa laman web anda ke **GitHub**, anda hanya perlu menyalin **SELURUH KOD** dalam fail `index.html` di bawah.

### 📋 Cara Menyalin dan Membawa ke GitHub:

1. **Salin Kod:** Klik butang **Copy** pada tetingkap kod `index.html` di bawah.
2. **Pergi ke GitHub:**
* Log masuk ke akaun **GitHub** anda.
* Cipta repository baharu (contohnya dinamakan: `papan-pemuka-jualan`).
* Klik **"Creating a new file"**.


3. **Dinamakan Fail:** Namakan fail tersebut tepat sebagai **`index.html`** (penting: mesti huruf kecil `index.html`).
4. **Tampal & Simpan:** Tampal (*paste*) kod yang anda salin tadi di dalam ruang teks GitHub, kemudian klik **Commit changes...**.
5. **Aktifkan Web (GitHub Pages):**
* Pergi ke menu **Settings** repository anda di GitHub.
* Klik **Pages** pada menu di sebelah kiri.
* Di bahagian *Branch*, pilih **main** (atau *master*) dan klik **Save**.
* Dalam tempoh 1–2 minit, GitHub akan memberikan pautan (*URL*) laman web live anda!
